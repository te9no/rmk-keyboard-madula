# v0.1.0-rc.10 — RynkのMadula表示配置を修正

Rynkでキーが等間隔のマトリクスとして表示されていた配置を、左右分割・列の段差・親指キーを含む配置へ変更しました。

- ZMKのphysical-layoutを基に、親指キーの回転角と回転中心を反映。下方へずれていたLANG1も親指キー群へ戻しました。
- 中央3キーの位置をZMKのMadula 53-key配置に合わせました。
- エンコーダー2個の操作を表示。押下キーと重ならないよう内側の空き領域に配置しています。
- 仮想ジェスチャー・スクロール用キーは下段で編集できます。
- 全64キーのマトリクス番号・順序と全5レイヤーの割り当てを維持しています。保存領域・スキーマIDは変更しません。

表示は編集用レイアウトです。中央3キーは別段に表現しており、筐体の寸法図ではありません。
今回の変更はMadulaのRynk表示が対象で、Vial定義とCornixTPの配置は変更していません。
rc.9のホスト切替対策・接続中+8 dBm・Dial分割送信、rc.8の残量修正を維持しています。

## ファイルの選択

| モジュール | Vial版 | Rynk版（gui.rmk.rs） |

| LPPS | madula-lpps.uf2 | madula-lpps-rynk.uf2 |

Rynk版の中央機を更新後、Rynkを再読み込みして再接続してください。
今回の表示修正のためにCornix左右を更新する必要はありません。
CornixTPには専用cornix-tp.uf2を使ってください。

## 確認状況

Madula TB Rynkの同じ配置修正コードを実機へ書き込み、再起動とPMW3610認識を確認しました。
修正後、ユーザーから了承とリリース依頼を受けています。他モジュールの実機表示は未確認です。
実際のRMKレイアウトパーサーによる圧縮・復号の一致、64キー・2エンコーダー、親指キーの回転位置を検査しています。
複数ホスト切替、電池持ち、接続先OSの0%通知停止など、前版からの未確認項目は継続します。

ビルドの由来はBUILD-PROVENANCE.md、配布ファイルのハッシュはSHA256SUMSを参照してください。
UF2は0x1000から配置するRMK SDCアプリです。旧SoftDeviceを上書きするため、ZMKアプリの更新ファイルではありません。
実機バックアップ・ペアリング情報は配布しません。
