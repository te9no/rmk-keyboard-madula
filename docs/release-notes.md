# v0.1.0-rc.9 — ホスト切替・送信出力・Dial改善

- #3: 登録済みBLEプロファイルは相手を指定した広告を使い、別の登録済みホストが割り込む接続競合を防ぐ方式に変更。未登録スロットは新規ペアリング用の広告を継続します。
- #4: Madula設定の接続中送信出力を+8 dBmに指定。共通設定を使うCornix左右にも適用します。
- #5: MadulaのDialを1クリック18°一括送信から6°×3回へ変更。キューへの投入間隔8ms、角度合計・方向・ボタン状態を維持します。Madulaの全6配布構成でdial-smoothを有効にしました。
- rc.8のバッテリー残量修正、rc.7のIQS/BLE入力改善、Rynk v0.2互換対応を維持しています。

## ファイルの選択

| モジュール | Vial版 | Rynk版（gui.rmk.rs） |
| --- | --- | --- |
| LPPS | madula-lpps.uf2 | madula-lpps-rynk.uf2 |
| PMW3610 / TB | madula-tb.uf2 | madula-tb-rynk.uf2 |
| IQS9151 | madula-iqs.uf2 | madula-iqs-rynk.uf2 |

中央機の更新でホスト切替・Dialを変更できます。Cornix左右の送信出力変更も適用する場合は左右のUF2も更新してください。
CornixTPは専用cornix-tp.uf2です。CornixTPのDial分割送信・送信出力は変更していません。
詳しい動作と比較手順は同梱のble-dial-issues.mdを参照してください。

## 実機確認と未確認事項

Madula TB Vialの同じ修正コードを書き込み、再起動、PMW3610認識、BLE暗号化接続をログで確認しました。
電池電圧1.297V・推定残量68%も取得できています。接続先OSに表示された残量や0%通知停止の確認は別途必要です。
Dialについてユーザーから「ダイヤルはオッケー」と動作確認を受けています。
他モジュール・Rynk版・Windowsの各ツールを網羅した実機確認ではありません。
複数ホスト間の切替時間、RPAホストの再接続、電池寿命への影響は未測定です。
分割送信中には最大約16ms＋キュー待ち時間が生じるため、高速回転・押し回しも引き続き確認してください。

ホスト側だけでペアリングを削除した場合は、キーボード側の対象プロファイルもクリアして再登録してください。
この変更では保存領域・スキーマIDは変更しません。

## 検証・配布

配布ビルドの由来はBUILD-PROVENANCE.md、ファイルの検証はSHA256SUMSを参照してください。
UF2は0x1000から配置するRMK SDCアプリです。旧SoftDeviceを上書きするため、ZMKアプリの更新ファイルではありません。
実機バックアップ・ペアリング情報は配布物に含めません。
